# Yasmin Santos — Beta 1.0

Site estático para GitHub Pages, com duas ofertas independentes:

- **Conteúdo exclusivo no site:** diário R$ 9,90, mensal R$ 34,90 e vitalício VIP R$ 199,00.
- **Privacy:** mensal R$ 20,00, trimestral R$ 55,00 e semestral R$ 99,90.

O checkout usa o mesmo Worker Cloudflare e diferencia cada produto pelo código do plano. O Privacy mantém identidade e checkout próprios; o checkout da página principal usa tema escuro e dourado.

Antes de publicar, configure os links públicos em `config.js`.
